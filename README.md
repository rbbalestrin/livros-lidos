# Livros Lidos

Uma rede social para registrar o que você lê e ver o que seus amigos estão lendo. Cada leitura vira uma entrada no diário, com data, nota e, se quiser, uma resenha. Quem te segue vê isso no feed.

O projeto está no começo. Ainda não tem código, só o recorte da primeira versão em [docs/produto.md](docs/produto.md).

O site sai primeiro, em português e inglês. Apps nativos para iOS e Android vêm depois, usando o mesmo backend.
